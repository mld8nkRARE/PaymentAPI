# PaymentAPI
 
Backend-приложение на ASP.NET Core для приёма платежей и возвратов с интеграцией платёжного провайдера ЮKassa. Архитектура спроектирована так, чтобы подключение нового провайдера не требовало изменений в бизнес-логике — только добавление новых файлов по существующему шаблону.
 
## Стек
 
- **C# / ASP.NET Core Web API**
- **Entity Framework Core** + **PostgreSQL**
- **ASP.NET Core Identity** + **JWT** (access + refresh токены)
- **MediatR** — доменные события
- **Yandex.Checkout.V3 SDK** — интеграция с ЮKassa

## Эндпоинты
 
### Аутентификация
 
| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/auth/register` | Регистрация пользователя |
| `POST` | `/api/auth/login` | Вход, выдача access/refresh токенов |
| `POST` | `/api/auth/refresh` | Обновление пары токенов по refresh-токену |
| `POST` | `/api/auth/logout` | Отзыв конкретной сессии *(требует авторизации)* |
| `POST` | `/api/auth/logout-all` | Отзыв всех активных сессий пользователя *(требует авторизации)* |
 
### Товары
 
| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/product` | Список товаров. `includeDeleted` — включить удалённые |
| `GET` | `/api/product/{id}` | Получение товара по ID |
| `POST` | `/api/product` | Создание товара |
| `DELETE` | `/api/product/{id}` | Пометка товара как удалённого (soft delete) |
| `POST` | `/api/product/{id}/stock/add` | Пополнение остатка на складе |
| `POST` | `/api/product/{id}/stock/remove` | Списание остатка со склада |
 
### Заказы
 
| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/orders` | Создание заказа |
| `POST` | `/api/orders/{id}/cancel` | Отмена заказа |
 
### Платежи
 
| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/payment` | Создание платежа. Заголовок `Idempotence-Key` обязателен |
 
### Возвраты
 
| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/refund` | Создание возврата по платежу. Заголовок `Idempotence-Key` обязателен |
| `GET` | `/api/refund/{id}` | Получение статуса возврата |
 
### Вебхуки
 
| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/payment_webhook/{provider}` | Приём уведомлений от платёжного провайдера (платежи и возвраты). IP отправителя проверяются до обработки тела запроса |
 
Большинство эндпоинтов требуют JWT-токен в заголовке `Authorization: Bearer <token>`.
